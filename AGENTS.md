# AGENTS.md

# Objetivo do Repositório

Este repositório possui foco educacional e foi criado para ensinar programação web para iniciantes, principalmente JavaScript, DOM, HTML, CSS e projetos práticos.

O objetivo é manter o conteúdo:

* didático
* progressivo
* organizado
* simples de entender
* fácil de navegar
* prático

---

# Público-alvo

Pessoas iniciando na programação, com pouca ou nenhuma experiência prévia.

O conteúdo deve sempre considerar:

* dificuldade gradual
* linguagem simples
* exemplos reais
* explicações completas
* evitar excesso de complexidade

---

# Regras Gerais

## Didática

Sempre:

* explicar o que é
* explicar por que usar
* explicar quando usar
* explicar como usar
* mostrar exemplos reais
* explicar possíveis erros comuns

Nunca:

* assumir conhecimento prévio
* usar explicações extremamente curtas
* pular etapas importantes
* remover contexto didático

---

# Estrutura

Manter organização consistente.

Exemplo:

```txt
conteudo-js/
conteudo-dom/
conteudo-html-css/
material-aovivo/
projetos/
desafios/
exercicios/
```

---

# README

O README principal deve:

* possuir sumário navegável
* explicar a estrutura do curso
* possuir links para módulos
* possuir links para projetos
* possuir links para exercícios
* facilitar navegação

---

# Exercícios

Os exercícios devem:

* possuir enunciado claro
* possuir exemplos
* possuir gabarito quando possível
* aumentar dificuldade gradualmente
* estimular prática real

---

# Projetos

Projetos devem:

* ser pequenos e progressivos
* possuir objetivo claro
* possuir descrição
* possuir tecnologias utilizadas
* possuir instruções de execução

---

# Código

Prioridades:

1. Clareza
2. Organização
3. Legibilidade
4. Simplicidade

Evitar:

* complexidade desnecessária
* otimizações prematuras
* abstrações difíceis para iniciantes

---

# Commits

Sempre:

* fazer commits pequenos
* usar mensagens claras
* manter histórico organizado

Exemplos:

* feat: adiciona exercícios de arrays
* docs: melhora README principal
* refactor: reorganiza exemplos de DOM
* chore: organiza estrutura do curso

---

# Fluxo de Trabalho

Ao modificar o repositório:

1. Analisar conteúdo atual
2. Melhorar explicações
3. Adicionar exemplos
4. Adicionar exercícios
5. Revisar organização
6. Atualizar README quando necessário
7. Fazer commit
8. Fazer push

---

# Importante

Este repositório é um material vivo e em constante evolução.
Priorizar sempre:

* qualidade didática
* clareza
* acessibilidade
* experiência do aluno
