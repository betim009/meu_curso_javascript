# Git

## Verificar status

```bash
git status
```

## Criar commit

```bash
git add .
git commit -m "mensagem"
```

## Enviar alterações

```bash
git push
```

# Padrões

## Conteúdo Didático

Todo conteúdo deve:

* explicar fundamentos
* possuir exemplos
* possuir exercícios
* possuir linguagem simples

---

# Exercícios

Preferencialmente:

* separados por nível
* com gabarito
* progressivos

---

# Projetos

Projetos devem possuir:

* README próprio
* descrição
* tecnologias
* instruções de execução

---

# README Principal

O README principal deve:

* possuir sumário
* possuir links internos
* organizar módulos
* facilitar navegação

---

# Commits

Mensagens recomendadas:

```txt
feat:
docs:
fix:
refactor:
chore:
```

Exemplos:

```txt
feat: adiciona exercícios de DOM
docs: melhora README do curso
refactor: reorganiza estrutura do módulo arrays
```
