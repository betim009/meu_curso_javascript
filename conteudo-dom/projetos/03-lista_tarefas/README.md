# Projeto: Lista de Tarefas

## Descrição

Mini-projeto prático que aplica múltiplos conceitos de DOM em conjunto:
adicionar tarefas digitadas pelo usuário, marcar como concluída ao clicar, remover tarefas e contar quantas estão pendentes.

## Tecnologias

- HTML5
- CSS3
- JavaScript (DOM puro, sem bibliotecas)

## Conceitos aplicados

- `querySelector` e `getElementById` (seletores)
- `createElement` e `appendChild` (criação de elementos)
- `addEventListener` com `click` e `keydown` (eventos)
- `classList.toggle` (manipulação de classes CSS)
- `.remove()` (remoção de elementos)
- `.trim()` e `.value` (captura de dados do input)

## Como executar

1. Abra o arquivo `index.html` diretamente no navegador
2. Digite uma tarefa no campo de texto
3. Clique em "Adicionar" ou pressione **Enter**
4. Clique no texto da tarefa para marcar como concluída
5. Clique no **×** para remover a tarefa

## Funcionalidades

- Adicionar tarefas com botão ou tecla Enter
- Marcar tarefas como concluídas (clicando no texto)
- Remover tarefas individualmente
- Contador de tarefas pendentes atualizado automaticamente
