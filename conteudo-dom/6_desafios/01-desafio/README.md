# Desafio: Soma de Dois Números

## Descrição

Mini-projeto de formulário que captura dois números, calcula a soma ao clicar no botão "Enviar" e exibe o resultado.

## Tecnologias

- HTML5
- CSS3
- JavaScript (DOM puro)

## Conceitos aplicados

- Captura de valor de campos `input` com `.value`
- Conversão de string para número com `parseInt()`
- Eventos inline (`onchange`, `onclick`)
- Exibição de resultado com `alert()`

## Como executar

1. Abra o arquivo `index.html` no navegador
2. Digite o primeiro valor
3. Digite o segundo valor
4. Clique em "Enviar" para ver a soma
