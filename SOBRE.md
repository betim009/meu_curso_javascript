# Sobre este Repositório

Este repositório reúne o material de um **curso de JavaScript para iniciantes**, organizado em módulos progressivos que vão do básico ao intermediário. O conteúdo cobre fundamentos da linguagem, manipulação do DOM, HTML/CSS e tópicos extras explorados em aulas ao vivo.

---

## Estrutura

### `conteudo-js/` — Fundamentos de JavaScript
Módulos teóricos com exemplos e atividades práticas, organizados por tema:

| Módulo | Conteúdo |
|--------|----------|
| `00-intro` | Introdução à linguagem |
| `01-dados` | Tipos de dados, arrays, objetos, métodos e datas |
| `02-condicoes` | if/else, operador ternário, switch/case |
| `03-arrays-loops` | Loops, métodos de array (map, filter, reduce) |
| `04-funcoes` | Tipos de funções, arrow functions, funções assíncronas |
| `05-json` | JSON: introdução e exercícios |
| `06-classes` | Classes e orientação a objetos |

Cada módulo inclui material explicativo, atividades com gabarito e projetos práticos.

### `conteudo-dom/` — Manipulação do DOM
Módulos focados em interação com o HTML via JavaScript puro:

| Módulo | Conteúdo |
|--------|----------|
| `1_seletores` | getElementById, querySelector, querySelectorAll |
| `2_createElements` | Criação e manipulação de elementos |
| `3_eventos` | Event listeners e eventos do DOM |
| `4_styles` | Manipulação de estilos via JS |
| `5_formularios` | Captura e validação de dados de formulários |
| `6_desafios` | Projetos e desafios práticos de DOM |

### `conteudo-html-css/` — HTML e CSS
Material de apoio com exemplos de HTML semântico, CSS e Flexbox, incluindo atividades com imagens de referência para layout.

### `material-aovivo/` — Material de Aulas ao Vivo
Código produzido e explorado durante as aulas em tempo real:

| Subpasta | Descrição |
|----------|-----------|
| `projeto_FABIO/` | Projeto de loja virtual com Bootstrap, renderização dinâmica de cards via JS e consumo de dados de um módulo `loja.js` |
| `FabioFlex/` | Exercício de layout com Flexbox e CSS |
| `simplesfullstack/` | Exemplo simples de aplicação fullstack com Node.js |
| `ts/` | Introdução a TypeScript: configuração e primeiros exemplos |
| `teste-play/` | Estrutura de testes E2E com Cucumber + Playwright + TypeScript |
| `js/` | Scripts de atividades feitos ao vivo |
| `old/` | Arquivos de sessões anteriores (fetch, scripts experimentais) |

---

## Público-alvo

Pessoas iniciando em programação web, com foco em JavaScript. O material assume pouco ou nenhum conhecimento prévio e evolui gradualmente até tópicos como funções assíncronas, classes, TypeScript e testes automatizados.

---

## Status

O repositório está **em constante atualização**, com novos módulos e atividades sendo adicionados conforme o curso avança.
